#  BudgetBot (Бот совместного учёта расходов)

Telegram-бот на базе **Aiogram 3**, предназначенный для удобного ведения совместного бюджета в группах (сожители, друзья, путешественники). Бот автоматизирует процесс распределения чеков за счёт интеграции ИИ (LLM через OpenRouter), который распознаёт позиции и автоматически классифицирует их по категориям.

##  Ключевые возможности

*   ** Управление группой:** Быстрое добавление участников прямо внутри группового чата.
*   ** Сканирование чеков (ИИ):** Распознавание фото чеков через OpenRouter API. Нейросеть сама собирает названия товаров, цены и соотносит их с нужными категориями.
*   ** Матричное распределение товаров:** Уникальная интерактивная Excel-подобная inline-сетка в Telegram. Вы можете галочками указать, кто именно из группы скидывается на конкретный товар в чеке.
*   ** Ручной ввод покупок:** Возможность добавить общую трату с кастомным выбором плательщика и участников вручную.
*   ** Умный взаимозачёт и оптимизация долгов:** 
    **Взаимозачёт:* сведение встречных долгов («Я тебе 500, ты мне 300» -> «Я тебе 200»).
    **Оптимизация:* Уникальный алгоритм (Greedy Match), минимизирующий количество транзакций (переводов) между всеми участниками.
*   **Напоминание о долгах:** Возможность в один клик отправить должнику вежливое уведомление в личные сообщения бота.
*   **Аналитика и ИИ-Советник:** 
    **Динамическое построение красивой круговой диаграммы (Pie Chart) трат за 7 дней средствами *Matplotlib*.
    **Генерация персональных финансовых советов и прогноза расходов до конца месяца от искусственного интеллекта на основе текущего темпа трат.

##  Технологический стек

*   **Язык:** Python 3.10+
*   **Фреймворк:** Aiogram 3.31.0 (Асинхронный)
*   **База данных:** SQLite + `aiosqlite` (Асинхронный ORM-less подход)
*   **Нейросеть (Vision & Text):** OpenRouter API (поддержка бесплатных и коммерческих моделей, например Gemini/Llama)
*   **Визуализация:** Matplotlib (режим рендеринга `Agg` без вызова GUI-окон)

## Быстрый запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлены шрифты с поддержкой кириллицы (Segoe UI, Arial или Calibri) для корректного рендеринга графиков в Matplotlib.

### 2. Клонирование и установка зависимостей
```bash
git clone <url_вашего_репозитория>
cd <папка_проекта>
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории и заполните его следующими ключами:
```env
BOT_TOKEN=ваш_токен_от_BotFather
OPENROUTER_API_KEY=ваш_ключ_openrouter
MODEL_NAME=openrouter/free # или любая другая модель, например google/gemini-2.5-flash
```

### 4. Запуск бота
```bash
python main.py
```

## Структура Базы Данных (SQLite)
*   `groups` — Хранение данных о подключенных Telegram-чатах.
*   `members` — Участники групп (связка `chat_id` и `user_id`).
*   `receipts` — Загруженные чеки и общие ручные траты.
*   `receipt_items` — Отдельные товарные позиции внутри чеков.
*   `receipt_item_members` — Таблица связей (Matrix M:N) для учета, кто именно скидывается на конкретный товар.
*   `debts` — Зафиксированные долги.
